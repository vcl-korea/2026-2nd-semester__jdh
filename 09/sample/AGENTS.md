# 9회 폴더 규칙

이 폴더는 6~8회에 PRD와 목업을 만든 `06` 폴더다. 9회에는 여기에 9회 자료를 더해,
서비스를 만들기 전에 사용자 흐름과 개발 계획을 정한다.

## 먼저 읽을 파일

- `00_course_rules.md` — 수업에서 만들 수 있는 것과 어려운 것
- `PRD.md` — 8회에 제출한 서비스 계획서
- `mockup/` — 6~8회에 만든 화면 목업. 화면 모양과 디자인을 참고만 한다

## 지킬 일

- 코드, HTML, 프로젝트 파일을 만들거나 고치지 않는다. 개발은 10회부터다.
- `PRD.md`와 `mockup/` 안의 파일은 고치지 않는다. 고칠 곳이 보이면 대화창에 알려만 준다.
- 파일을 고치라고 하면, 요청에 적힌 파일과 항목만 고친다.
- 8회까지 쓴 다른 파일과 폴더는 옮기거나 지우지 않는다.
- PRD에 없는 기능을 새로 넣지 않는다.
- 답은 한국어로 짧게 한다. 모르는 말은 쉬운 말로 풀어 쓴다.
